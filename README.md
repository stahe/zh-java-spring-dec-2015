## 📚 关于本文档的信息

本教学资料面向大学初学者。它将课程的理论概念与实践练习相结合。

### 学习目标

主要目标是从**专业**角度教授Java语言。因此，本课程主要基于**[Spring](http://spring.io/)**框架，这是一种用于**JEE**（Java企业版）开发的技术。

从逻辑上讲，本模块作为进阶JEE专业课程前的入门课程。
